# 索米梦境互动网站

索米互动作品集，包含唤醒、来信、房间探索、换装拍照、照片墙、飞行小游戏与晚安页面。

## 查看与下载

1. 在此分支的 GitHub 页面选择 **Code → Download ZIP**。
2. 解压后用现代浏览器打开 `index.html`。
3. 也可以通过静态 HTTP 服务运行此目录。当前保存源码，不代表已开通 GitHub Pages。

`index.html` 内嵌脚本、样式和图片，不需要安装依赖。
